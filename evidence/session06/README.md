# Session 06 outside-user evidence (protocol sep29_v2)

Real outside-user task tests of the running ClauseGuard product on 2026-10-05. 3 new participants (U003, U004, U005), none of them on the five-person team and none who took part before. Who they were, without names: three flatmates of the observer, outside the five-person team. Each gave verbal consent before their trials.

Each did one task without the tool (plain text editor) and one with ClauseGuard (desktop app), with task order and tool order swapped between participants; 180-second limit. The clock stopped when the participant stated the answer; typing the answer was not timed. The decision rule these results feed (`docs/decisions/midpoint_rule.json`) was merged before the first session.

Files:
- `tasks.csv`: one row per trial (task, condition, correct, seconds, model ID, protocol)
- `U00X_<task>_<condition>_sep29_v2.json`: timestamped trial records with the exact prompt read aloud, number of readings, the answer, interface and observer notes
- `session_notes.md`: notes written up after the sessions, including measurement notes
- No screenshots were taken.

The answer key is not in the repository. No names, emails, faces or contact details are included.
