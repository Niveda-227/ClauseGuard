\# Session 05 outside-user evidence (protocol sep29\_v2)



Real outside-user task tests of the running ClauseGuard product on 2026-09-29. 1 participant (U002), outside the five-person team, gave verbal consent before their trials. They did one task without the tool (plain text editor) and one with ClauseGuard (desktop app), 180-second limit per trial. The clock stopped when the participant stated the answer; answer entry was not timed.



Files:

\- `tasks.csv` - one row per trial: task, condition, correct, seconds, model ID, protocol

\- `U002\_<task>\_<condition>\_sep29\_v2.json` - timestamped trial records including the exact prompt read aloud, number of readings, the answer, interface and observer notes

\- `session\_notes.md` - notes written during the sessions

\- `screenshots/` - one screen-only screenshot taken with consent



The answer key is not in the repository. No names, emails, faces or contact details are included.
