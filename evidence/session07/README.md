# Session 07 outside-user evidence (protocol sep29_v2)

Real outside-user task tests of the running ClauseGuard product on 2026-10-19. 2 new participants (U006, U007), none of them on the five-person team. Who they were, without names: U006 (classmate) and U007 (classmate). Consent was confirmed before their trials.

Each did one task without the tool (plain text editor) and one with ClauseGuard (desktop app), with task order and tool order swapped between participants; 180-second limit. The clock stopped when the participant stated the answer; typing the answer was not timed.

The app in these trials is the Session 07 product: per-category thresholds and the start of each sentence shown in the results list. Task F1's answer sentence is deliberately not flagged by the app, so F1 shows what happens when the app misses a clause.

Files:
- `tasks.csv`: one row per trial (task, condition, correct, seconds, model ID, protocol)
- `U00X_<task>_<condition>_sep29_v2.json`: timestamped trial records with the exact prompt read aloud, number of readings, the answer, interface and observer notes
- `session_notes.md`: notes written up after the sessions, including measurement notes
- `screenshots/`: screen-only screenshots (2 files)

The answer key is not in the repository. No names, emails, faces or contact details are included.
