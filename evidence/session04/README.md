\# Session 04 outside-user evidence



Real outside-user task tests run on 2026-09-22. One participant (U001), outside the

team, gave verbal consent before each trial. Two trials: task A1 without the tool in a

plain text editor, and task B1 with the ClauseGuard desktop app, 180-second limit,

protocol sep22\_v1.



Files here:

\- `tasks.csv` — one row per trial, with correctness, time and the model ID

\- `U001\_A1\_manual\_sep22\_v1.json`, `U001\_B1\_clauseguard\_sep22\_v1.json` — the timestamped

&#x20; raw records, including the participant's answer, my observation and the interface used

\- `session\_notes.md` — notes written during the session



No names, emails, faces or private document text are included. No screenshots were taken (participant declined).
